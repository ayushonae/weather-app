# Weather App

A modern weather app built using:

- HTML
- CSS
- JavaScript
- Open-Meteo API

## Features

- Live weather data
- Dynamic backgrounds
- Weather-based icons
- Day/Night icon switching
- Responsive UI
- Enter key support

## Live Demo

[Live Website](https://ayushonae.github.io/weather-app/)

## Technologies Used

- Open-Meteo API
- Fetch API
- Async/Await
- DOM Manipulation
